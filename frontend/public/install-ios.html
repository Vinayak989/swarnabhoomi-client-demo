तुमच्या iPhone वर स्वर्णभूमी अॅप

होम स्क्रीनवर अॅप जोडा. त्याच्या चिन्हावर टॅप केल्यावर स्वर्णभूमी स्वतंत्र विंडोमध्ये उघडेल.

  1. हे पान Safari मध्ये उघडा.लिंक WhatsApp मध्ये उघडली असल्यास “Open in Safari” निवडा.
  2. Share वर टॅप करा. नंतर Add to Home Screen निवडा.Share दिसत नसल्यास Safari च्या मेनूमध्ये तो पर्याय उघडा.
  3. Open as Web App दिसत असल्यास तो सुरू ठेवा आणि Add दाबा.
  4. होम स्क्रीनवरील स्वर्णभूमी चिन्हावर टॅप करून अॅप उघडा.

अॅप उघडण्यासाठी खालील बटणावर टॅप करा.
